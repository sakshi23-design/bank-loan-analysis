# Bank Loan Analysis - SQL End to End Project

Business Problem: Bank wants to identify who is defaulting and which loan type is riskiest.

## Dataset
Bank Loan Dataset (Customers, Loans, Payments)

## Tools Used
MySQL, JOINs, GROUP BY, Window Functions, Views

## Key Insights
- Default Rate: 6.8%
- Personal Loans have highest default at 9.8%
- Top defaulters are 90+ days overdue

- bank_loan_analysis.sql - All queries
